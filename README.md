# Projeto Aerocode - Interface de Gestão Aeronáutica (AV2)
Este repositório contém o desenvolvimento da primeira interface gráfica (GUI) do sistema de gestão de produção de aeronaves da Aerocode. O projeto marca a evolução de um sistema que antes operava apenas via linhas de comando (CLI) para uma aplicação web moderna, projetada para facilitar o dia a dia de engenheiros de produção e aeronáuticos.

## A Proposta

A transição para uma interface visual foi motivada pela necessidade de reduzir a curva de aprendizado e tornar a gestão de aeronaves mais intuitiva, especialmente visando a expansão para grandes parceiros globais como Boeing, Airbus e Embraer.

Para isso, o desenvolvimento seguiu um fluxo de trabalho estruturado:

* Planejamento e Requisitos: Entendimento das necessidades dos engenheiros e definição dos objetivos do negócio.

* Arquitetura de Informação: Criação de wireframes de baixa fidelidade para organizar a estrutura básica sem preocupações estéticas imediatas.

* Mapeamento de Navegação: Definição do fluxo do usuário (user flow) para garantir que cada tarefa no sistema seja lógica e rápida.

## Tecnologia
O projeto foi construído como uma Single Page Application (SPA) utilizando React. Essa escolha permite uma navegação fluida e respostas rápidas, já que o uso do Virtual DOM garante que apenas os elementos necessários sejam atualizados quando os dados mudam.

A aplicação é um protótipo funcional preparado para rodar em:

* Windows 10 ou superior.

* Linux Ubuntu 24.04.03 e suas distribuições derivadas.
